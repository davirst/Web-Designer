# Breakfast Website Project

## Overview
This website provides users with interactive breakfast-related content, including clickable food images, recipe boxes, and nutritional information. The site is designed to be visually appealing, user-friendly, and informative.

---

## Pages & Features

### 1. Home Page
- Features a breakfast-themed image with three clickable areas:
    - Egg → links to https://en.wikipedia.org/wiki/Egg
    - Sausage → links to https://en.wikipedia.org/wiki/Sausage
    - Bacon → links to https://en.wikipedia.org/wiki/Bacon
- Source of the image: https://www.etsy.com/nz/listing/685798348/hand-drawn-breakfast-clip-art-commercial

### 2. Recipe Page
- Displays at least three recipe boxes visible to users.
- Each recipe box includes hover effects to highlight and provide interactivity.
- Recipes include:
    1. Italian Sausage Links  
       Source: https://www.johnsonville.com/products/mild-italian-links.html  
       Instructions have been adapted and formatted for clarity.
    2. Basic Fried Eggs  
       Source: https://www.eggs.ca/recipes/basic-fried-eggs
    3. Crispy Bacon  
       Source: https://www.foodnetwork.com/how-to/packages/food-network-essentials/how-to-cook-bacon

Note: All recipe instructions have been restructured to improve readability and presentation.

### 3. Nutrition Page
- Contains two side-by-side elements:
    1. A text block displaying a motivational or informational saying about breakfast.
    2. A styled nutrition table with visible row borders for clarity.
- The layout ensures content is easy to read and visually balanced.

---

## Technologies & Tools
- HTML, CSS, JavaScript
- CSS Hover Effects for recipe boxes
- Styled tables for nutritional information
- Interactive image mapping for the Home Page

---

## Project Features
- Interactive clickable images linking to Wikipedia pages.
- Visually appealing recipe cards with hover effects.
- Organized and readable nutritional information.
- User-friendly layout across all pages.
